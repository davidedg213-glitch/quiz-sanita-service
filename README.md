# Preparati - Simulatore Sanitaservice ASL BA

È pronta la prima versione privata locale, con 1.500 quesiti sintetici, account di test, simulazioni con timer e salvataggio, report e storico.

**Per provarla:** fai doppio clic su `Avvia prova privata.cmd`, attendi il browser e crea un account dedicato al test. La prova è disponibile solo sul tuo computer. Per fermarla premi Ctrl+C nella finestra di avvio.

- [Stato della realizzazione e verifiche](docs/realizzazione/01_prima_versione_privata.md)

Il nome è provvisorio. I contenuti non sono la banca ufficiale. Supabase, pagamenti, studio e ripasso verranno integrati nei passaggi successivi; la versione corrente non è pronta per la vendita.
